# Z2: QC Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade MonitoringFindingsPage into a quality overview: severity summary cards with run-over-run delta badges, a findings trend chart, rule distribution, and a code filter — backed by fixed/new/remaining counters on ExportRun and a quality-history endpoint.

**Architecture:** Backend adds 3 counter columns to `export_runs` (computed in `persist_findings` before the feed-keyed delete), one new read-only endpoint, and extends the existing quality-findings response. Frontend adds `@mantine/charts` and restructures the existing findings page in place.

**Tech Stack:** FastAPI, SQLAlchemy async, Alembic, Pydantic; React 19, Mantine, @mantine/charts (recharts peer), TanStack Query.

**Spec:** `docs/superpowers/specs/2026-09-12-qc-page-design.md`

## Global Constraints

- Same gates, i18n parity, logger style, docs-in-commit rules as `2026-09-12-z1-ai-restarbeiten.md` (see that plan's Global Constraints).
- Migrations ONLY via `uv run alembic revision --autogenerate -m "..."`; strip unrelated drift from the generated file; verify with `uv run alembic upgrade head`.
- `@mantine/charts@9.5.2` + `recharts` are the ONLY new dependencies (operator-approved).
- Delta key is `(code, product_id, field)` — a message-only change counts as remaining.

```python
from fastapi import Depends, HTTPException, Query

@router.get("/feed-sources/{feed_source_id}/quality-history")
async def get_quality_history(
    feed_source_id: int,
    limit: int = Query(default=30, ge=1, le=100),
    _user: str = Depends(require_user),
    db_session: AsyncSession | None = Depends(get_db_session),
):
    session = _require_db(db_session)
    feed_source = await session.get(FeedSource, feed_source_id)
    if feed_source is None:
        raise HTTPException(status_code=404, detail="feed source not found")
    rows = list((await session.execute(
        select(ExportRun)
        .where(ExportRun.feed_source_id == feed_source_id)
        .order_by(ExportRun.id.desc())
        .limit(limit)
    )).scalars().all())
    return {"rows": [
        {
            "id": row.id,
            "started_at": row.started_at.isoformat(),
            "product_count": row.product_count,
            "critical": row.critical_finding_count,
            "warning": row.warning_finding_count,
            "info": row.info_finding_count,
            "fixed": row.fixed_finding_count,
            "new": row.new_finding_count,
            "remaining": row.remaining_finding_count,
        }
        for row in reversed(rows)
    ]}
```
