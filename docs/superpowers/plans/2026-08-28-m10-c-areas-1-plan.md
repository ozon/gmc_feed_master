# M10-c Areas I Implementation Plan (Login polish, Dashboard, Setup, Products)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the M10-c areas — Dashboard (§4.2), Setup with both tabs (§4.3), Products (§4.4), plus Login polish (§4.1) — on top of the M10-b foundation, wired into the router, so M10-d can add Pipeline Editor, Monitoring, Export and plugin infra.

**Architecture:** All server state via TanStack Query hooks (`src/api/`); URL params for context (no context store); components under `src/features/<area>/`; shared components from M10-b reused (StateViews, ConfirmModal, CopyField); forms via TanStack Form (`useForm` + `Field` render props over Mantine inputs); tables via TanStack Table v9 (`useTable` + `rowPaginationFeature`) with manual server-side pagination.

**Working tree:** All work happens in the isolated worktree created by the executing skill (branch `m10-c-areas`, base = current `main`). All frontend commands run from `<worktree>/frontend`.

## Global Constraints

- No comments in code (repo convention). TypeScript strict.
- All user-facing strings via `t()`; every new key added to BOTH `public/locales/en/<ns>.json` and `public/locales/de/<ns>.json` (key trees must stay identical; typed keys come from `en` automatically).
- Every data view implements loading (`LoadingState`), empty (`EmptyState` + primary action where meaningful), error (`ErrorState` + retry) states.
- Every mutation: success or error notification (`notifySuccess` / `notifyMutationError`); 422 `{"errors":[...]}` payloads are additionally rendered per-field in the form and summarized in one notification (design §2.5).
- After every mutation: invalidate affected query keys via the central factory (`src/api/queryKeys.ts`); server state is never copied into client state.
- Numbers via `Intl.NumberFormat` parameterized with the active i18next language; relative timestamps via dayjs (`relativeTime` plugin, active locale). Never format by hand.
- Full gate per task, from `frontend/`: `npm test -- --run && npm run typecheck && npm run build`.
- Tests: vitest + Testing Library, jsdom; fetch stubbed via `stubFetch` from `src/test/fetch.ts` (locale serving is layered automatically). Component/App tests use the shared `render` helper.
- M10-b test conventions (binding, they were review-verified): Mantine `Select` → `getByRole('combobox', { name })`; readonly inputs → `toHaveAttribute('readonly')`; `userEvent.setup()` replaces `navigator.clipboard` — stub it AFTER `setup()` via `Object.defineProperty` when a test asserts copy behavior.
- Mantine docs: `https://mantine.dev/llms.txt` is the index — fetch the relevant per-component page before writing against an unfamiliar component. Context7 rule remains in force.
- If a step's expectation fails: fix forward only when small and faithful; otherwise report BLOCKED with details. All deviations go into the final report for the reviewer.

## Backend ground truth (verified against M10-a code 2026-08-28)

- `GET /dashboard/summary` → `{counts:{clients,feed_sources,active_products,failed_last_exports}, clients:[{id,name,status,feed_sources:[{id,client_id,name,source_format,item_count,last_export_at,last_export_status,last_run_at,last_run_status}]}]}`
- `GET /clients` → `ClientOut[] {id,name,contact_details,status,created_at}`
- `POST /clients` (ClientCreate `{name, contact_details?, status?}`) → 201 ClientOut; 409 duplicate name
- `PUT /clients/{id}` (ClientUpdate; null fields dropped) → ClientOut; 404 absent; 409 duplicate
- `DELETE /clients/{id}` → 204; 409 if any of the client's feeds has an active run; cascades all per-feed data + client-scoped plugin rows
- `POST /clients/{cid}/feed-sources` (FeedSourceCreate `{name,source_format,cron_expression?,target_country?,target_language?,currency?,source_url?}`) → 201 FeedSourceOut; 404 unknown client; 422 invalid cron (detail string)
- `GET /clients/{cid}/feed-sources` → FeedSourceOut[]
- `GET /feed-sources/{id}` → FeedSourceOut
- `PUT /feed-sources/{id}` (FeedSourceUpdate — includes `history_retention_count` ≥1, `volume_drop_threshold_pct` 0–100, `configuration` JSONB) → FeedSourceOut; 404; 422 invalid cron (detail string)
- `DELETE /feed-sources/{id}` → 204; 409 active run; cascades per-feed data
- FeedSourceOut fields: id, client_id, name, source_format, cron_expression, target_country, target_language, currency, source_url, feed_type, history_retention_count, volume_drop_threshold_pct, configuration, export_url, created_at, updated_at
- `POST /feed-sources/{id}/export-token/rotate` → `{export_token, export_url}`; 404
- `GET /feed-sources/{id}/products?stage=raw&page=1&page_size=50&q&status=all&sort=product_id` → `{items,total,page,page_size}`; item = product_id, id, status, last_seen_at + baseline fields (title, description, link, image_link, availability, price, condition); `stage=processed` → 501; unknown stage/status/sort → 422
- `GET /feed-sources/{id}/products/{product_id}` → `{product_id,status,content_hash,config_hash,last_seen_at,removed_at,raw_data}`; 404 absent
- `GET /feed-sources/{id}/field-mapping` → `{version,auto_mapped,source_fields:[{name,kind,sub_fields}],mappings:{source:{target,origin}}}`; origin ∈ {auto, synonym, manual}
- `PUT /feed-sources/{id}/field-mapping` body `{mappings:{source:{target}}}` → FieldMappingOut; 422 `{"errors":[strings]}` on unknown attribute / positional target / kind incompatible / duplicate target
- `POST /feed-sources/{id}/field-mapping/auto` → FieldMappingOut (auto|synonym origins, manual entries preserved); 422 `{"errors":["no source fields observed yet"]}` when nothing observed
- `GET /registry/attributes` → `[{name,kind,required,sub_fields:[{name,type,required}],enum_values}]`; required ∈ {required, conditional, optional, deprecated, removed}
- Mapping target grammar: `attr` or `attr.subfield` ONLY; sub-field paths exist only for structured kinds (`structured`, `repeated_structured`); positional paths are a guaranteed 422 — the UI must never offer them
- `GET /feed-sources/{id}/ingestion-runs?limit&offset` → `IngestionRunOut[] {id,status,started_at,completed_at,processed_count,failed_count,error_message,statistics}`; status ∈ {pending, running, success, error, skipped}
- `GET /feed-sources/{id}/quality-findings` → `{ingestion_run_id,counts:{critical,warning,info},findings:[{severity,code,field,message,product_id,details}]}`

```ts
export function useClients() {
  return useQuery({ queryKey: queryKeys.clients, queryFn: () => apiGet<ClientRow[]>('/clients') });
}
export function useFeedSource(id: number | string) {
  return useQuery({
    queryKey: queryKeys.feedSource(id).detail,
    queryFn: () => apiGet<FeedSourceRow>(`/feed-sources/${id}`),
  });
}
export function useFieldMapping(feedSourceId: number | string) {
  return useQuery({
    queryKey: queryKeys.feedSource(feedSourceId).mapping,
    queryFn: () => apiGet<FieldMappingDoc>(`/feed-sources/${feedSourceId}/field-mapping`),
  });
}
export function useRegistryAttributes() {
  return useQuery({
    queryKey: queryKeys.registryAttributes,
    queryFn: () => apiGet<RegistryAttribute[]>('/registry/attributes'),
    staleTime: Infinity,
  });
}
export function useProductList(feedSourceId: number | string, params: {page: number; page_size: number; q?: string; status?: string; sort?: string}) {
  return useQuery({
    queryKey: queryKeys.feedSource(feedSourceId).products(params),
    queryFn: () => apiGet<ProductsPageResponse>(`/feed-sources/${feedSourceId}/products?${buildProductsQuery(params)}`),
    placeholderData: keepPreviousData,
  });
}
export function useProductDetail(feedSourceId: number | string, productId: string | null) {
  return useQuery({
    queryKey: queryKeys.productDetail(feedSourceId, productId ?? ''),
    queryFn: () => apiGet<ProductDetail>(`/feed-sources/${feedSourceId}/products/${encodeURIComponent(productId!)}`),
    enabled: productId !== null,
  });
}
export function useIngestionRuns(feedSourceId: number | string, active: boolean) {
  return useQuery({
    queryKey: queryKeys.feedSource(feedSourceId).runs,
    queryFn: () => apiGet<IngestionRunRow[]>(`/feed-sources/${feedSourceId}/ingestion-runs?limit=50`),
    refetchInterval: active ? 5000 : false,
  });
}
export function useQualityFindings(feedSourceId: number | string, active: boolean) {
  return useQuery({
    queryKey: queryKeys.feedSource(feedSourceId).findings,
    queryFn: () => apiGet<QualityFindingsResponse>(`/feed-sources/${feedSourceId}/quality-findings`),
    refetchInterval: active ? 5000 : false,
  });
}
```

```ts

useDeleteFeedSource(id) → apiDelete(`/feed-sources/${id}`)               → invalidate dashboardSummary, clients
useRotateExportToken(id) → apiPost(`/feed-sources/${id}/export-token/rotate`) → invalidate feedSource(id).detail
useSaveFieldMapping(id, mappings) → apiPut(`/feed-sources/${id}/field-mapping`, {mappings}) → invalidate feedSource(id).mapping
useAutoMap(id) → apiPost(`/feed-sources/${id}/field-mapping/auto`)       → invalidate feedSource(id).mapping
```
