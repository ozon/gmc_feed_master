Behavior (mirrors the current onDragEnd exactly):

NO — binding: return `null` for "no state change" so the wrapper can skip setLocal. Design: any path that today does NOT call setLocal returns `null`; paths that do call setLocal return the next array).
- Anything else (no `over`, palette drop not onto droppable, workspace drop onto the droppable itself) → `null`.

`PipelinePage.onDragEnd` wrapper:

```tsx

    const next = applyDragEnd(local, event);
```

`frontend/src/features/pipeline/dndUtils.ts` — append (imports already present: `addInstance`, `reorderInstances` are in the same file; `PipelineInstance` type already imported):

```ts
export function applyDragEnd(
  instances: LocalInstance[],
  event: {
    active: { id: string | number; data?: { current?: unknown } };
    over: { id: string | number } | null;
  },
): LocalInstance[] | null {
  const activeData = event.active.data?.current as
    | { source?: string; plugin?: { id: string; name: string } }
    | undefined;
  if (event.over?.id !== 'workspace-droppable' && activeData?.source !== 'workspace') return null;
  if (activeData?.source === 'palette' && activeData.plugin && event.over?.id === 'workspace-droppable') {
    return addInstance(instances, activeData.plugin);
  }
  if (activeData?.source === 'workspace' && event.over && event.over.id !== 'workspace-droppable') {
    const fromIdx = instances.findIndex((i) => i.clientId === event.active.id);
    const toIdx = instances.findIndex((i) => i.clientId === event.over!.id);
    if (fromIdx >= 0 && toIdx >= 0) return reorderInstances(instances, fromIdx, toIdx);
  }
  return null;
}
```

(`plugin` gets only `{ id, name }` — addInstance takes exactly that shape.)
